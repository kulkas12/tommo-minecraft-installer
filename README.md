# TomMo — instalator paczki Minecraft

[Pobierz instalator TomMo 1.0.0 dla Windows](https://github.com/kulkas12/tommo-minecraft-installer/releases/download/v1.0.0/TomMo-Instalator-1.0.0.exe)

Instalator przygotowuje osobny profil gry z Minecraft Java 26.3, Fabric Loader 0.20.1, Fabric API, Macaw’s Furniture, Decorative Computers i teksturami TomMo.

## Instalacja

1. Uruchom Minecraft Java 26.3 co najmniej raz w oficjalnym launcherze.
2. Zamknij grę i Minecraft Launcher.
3. Pobierz i uruchom instalator. Kliknij **Zainstaluj TomMo**.
4. Otwórz oficjalny launcher, zaloguj się swoim kontem Microsoft i wybierz **TomMo — Minecraft 26.3**.
5. Kliknij **Graj**, a następnie w trybie wieloosobowym wybierz **TomMo**. Hasło serwera otrzymasz osobno od właściciela.

## Wymagania

Windows 10/11 z .NET Framework 4.8, oficjalny Minecraft Launcher, własne konto Microsoft z Minecraft Java oraz internet podczas instalacji.

Paczka używa osobnego folderu `%APPDATA%\.minecraft\TomMo-26.3`. Instalator zachowuje inne profile i tworzy kopie zmienianych plików. Mody pobiera ze źródeł projektów i sprawdza ich sumy kontrolne.

Instalator nie jest podpisany cyfrowo. Przetestowano pełną i ponowną instalację w odizolowanym folderze. Suma SHA-256 znajduje się przy plikach wydania.
